# Fix AGENTS.md drift

AGENTS.md no longer matches the code. Facts below were verified against
the working tree on 2026-09-30. All are documentation fixes (or
intelligence moves into plan files) — no code changes.

## Drift list

1. **Timestamp storage**: AGENTS.md says timestamps are stored as
   `INTEGER` Unix seconds in one copy and as `TEXT` RFC3339 in another
   (the file contains the architecture section twice). The migrations
   (`migrations/20260517082423.sql`, `20260614075800.sql`) and the
   sqlite port (`port/state/sqlite/port.go`, `time.Unix(...)` at
   read/write) use **INTEGER Unix seconds**. Correct both copies.

2. **Duplicate content**: AGENTS.md embeds the full document twice
   ("# AGENTS.md" appears twice with overlapping-but-diverged bodies,
   which is where the drift above comes from). Collapse to a single
   authored copy.

3. **SQLite driver**: AGENTS.md says `modernc.org/sqlite`; the code
   imports `github.com/glebarez/go-sqlite` (`port/state/sqlite/port.go`).

4. **`log_events` table**: AGENTS.md says it "has not been created yet".
   `log_entries` already exists in migrations (id, action, session,
   payload TEXT, timestamp). Update; also correct the table name
   (`log_entries`, not `log_events`).

5. **Port structure**: AGENTS.md describes a single
   `adapter/state/repository.go` + `port/state/sqlite/port.go`. Per the
   settled decisions in `docs/discussions/20260930_api_specs_state.md`
   the target structure is split adapter packages (`adapter/state/note`
   with `note.Store`, `adapter/state/log` with `log.EventLog`). Either
   update after that refactor lands, or note the planned state in the
   meantime — do not document the current shape as final.

6. **Constructor naming**: AGENTS.md calls the sqlite constructor
   `func main(file string)` "unconventional and may be a placeholder".
   It is still `func main` in the code; keep the note but soften the
   "may be a placeholder" wording to "known wart, candidate for a
   boring `New*` rename" (drop point 5 naming aside).

7. **Port/adapter naming convention**: AGENTS.md says packages are
   named after domain concepts; extend the Type naming section with the
   settled rule that ports are also named after the storage/aggregation
   concept they implement (`note.Store`, `log.EventLog`), and that
   enums-for-storage get explicit `*FromStorage` converters in
   `port/state/sqlite`.

## Acceptance criteria

- Single-copy AGENTS.md, no duplicated sections.
- Timestamp format, driver package, and table names match the code.
- Architecture tree matches working tree structure.
- No factual claims that contradict `docs/discussions/` decisions.
